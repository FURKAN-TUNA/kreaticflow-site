How we build

The studio has one founder. Claude Code does the engineering: validation, code, tests, store listings and releases. The founder sets direction and signs off on every production release.

Validate first

Every idea is reviewed by skeptical agents against real store data before any code is written. Most ideas are rejected at this stage.

Build with tests

Flutter for apps, Unity and Blender for 3D games. Our apps ship with large automated test suites: more than 800 tests for Shikaku and more than 1,300 for Shogi.

Ship worldwide

Localized store listings (Pikselce ships in 11 languages), released through the Google Play Publishing API.
