Privacy Policy

Fabrika Pano · KreaticFlow · Last updated 7 November 2026

"Fabrika Pano" is an internal Android app operated by KreaticFlow. It shows KreaticFlow's own business statistics (app downloads, ratings, sales, YouTube channel numbers) as home-screen widgets on the owner's phone. It is not published on Google Play or offered to the public, and no one other than the studio owner signs in to it.

Google data the app accesses

With the owner's consent, the app uses read-only Google APIs to read data about KreaticFlow's own accounts:

  • Google Cloud Storage (read-only): the Google Play statistics and sales reports that Play exports for the studio's own developer account;
  • Google Play Developer API: reviews and release status of the studio's own apps;
  • YouTube Data API and YouTube Analytics API (read-only): public counters, video list and aggregate analytics of the studio's own channel;
  • Google Analytics Data API (read-only): aggregate event counts of the studio's own app properties;
  • AdMob API (read-only): aggregate earnings and impression reports of the studio's own apps.

The app does not read any end user's personal data, other people's accounts, email, contacts or files.

How the data is used, stored and shared

  • Data is used only to draw the owner's statistics on the owner's phone.
  • Data and summaries are stored only on that phone. Access tokens are managed by Google Play services; the app stores no passwords.
  • No data is sold, shared with third parties, sent to KreaticFlow servers, or used for advertising.

Revoking access

Access can be revoked at any time from the Google Account security settings (myaccount.google.com/permissions), or by uninstalling the app, which deletes all locally stored data.

Google policies

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
