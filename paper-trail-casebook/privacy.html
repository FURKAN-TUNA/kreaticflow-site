Privacy Policy

The Paper Trail Casebook uploader · KreaticFlow · Last updated 22 October 2026

"Paper Trail Casebook Uploader" is an internal tool operated by KreaticFlow. Its only purpose is to publish and manage videos on KreaticFlow's own YouTube channel, The Paper Trail Casebook. It is not offered to the public, and no one other than the channel owner signs in to it.

Google and YouTube data the tool accesses

With the channel owner's consent, the tool uses the YouTube API Services to:

  • read the basic details of the authorized channel (its ID and title), to make sure uploads go to the right channel;
  • upload videos, thumbnails and caption files, and set titles, descriptions and scheduled publish times;
  • read the channel's own video list and processing status, to keep a schedule of upcoming episodes;
  • read aggregate YouTube Analytics reports (views, watch time, retention) for the channel's own videos.

The tool does not access viewers' personal data, comments, subscribers' identities, or any other channel.

How the data is used, stored and shared

  • Data is used only to run the channel: uploading episodes and deciding what to produce next.
  • The OAuth refresh token is stored only on the operator's own computer, encrypted with the operating system's credential store. Analytics summaries are kept as local files.
  • No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from the Google Account security settings (myaccount.google.com/permissions). Revoking access stops the tool; locally stored tokens are then deleted.

YouTube and Google policies

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
